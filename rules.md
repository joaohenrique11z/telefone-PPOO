# rules.md - Diretrizes Restritas para Resolução (PPOO)

**Objetivo:** Este documento define as regras absolutas e eliminatórias que a IA deve seguir ao auxiliar na resolução da Lista de Exercícios Avaliativa I da disciplina de Padrões de Projetos Orientados a Objetos.

## 1. Escopo e Regras de Entrega
* A atividade deve ser desenvolvida e entregue em dupla, a mesma dos seminários da disciplina[cite: 5, 6].
* A avaliação será uma arguição sobre o código desenvolvido[cite: 5].
* Criar exatamente 5 repositórios separados no GitHub (um para cada questão). A entrega será o link destes 5 repositórios[cite: 5].
* Para as três primeiras questões, deve-se usar o código inicial do `src.zip` fornecido[cite: 5].

## 2. Comportamento Exigido da IA (O Tutor)
* **PROIBIDO FORNECER CÓDIGO COMPLETO:** A IA jamais deve entregar a solução final pronta[cite: 5].
* **CICLO DE TUTORIAL:** A IA deve fornecer o auxílio em um ciclo estrito de: **Passo -> Commit -> Passo -> Commit**. 
* A IA deve guiar a dupla iterativamente. Só se avança para o próximo passo metodológico depois de configurar a base do anterior[cite: 5].

## 3. Regras de Documentação e Versionamento (CRITÉRIO ELIMINATÓRIO)
* Todo uso da IA deve ser documentado através de **commits no repositório**, especificando quais prompts foram utilizados e justificando os ajustes manuais feitos sobre a sugestão da IA (por que a IA não serviu totalmente e como o humano melhorou)[cite: 5].
* **Fluxo Obrigatório Passo a Passo:**
  1. A IA sugere um **Passo** de implementação.
  2. O aluno implementa, testa e faz os comentários no código explicando o raciocínio/ajuste.
  3. O aluno faz o **Commit** correspondente àquela etapa exata.
  4. Repete-se o ciclo.
* Os commits devem ser curtos, agrupar apenas ajustes correlatos e usar mensagens que deem o resumo daquele conjunto de alterações[cite: 5].
* O detalhamento das decisões deve usar os comentários de linha do código e os comentários do GitHub[cite: 5].
* **Regra de Ouro Eliminatória:** "Quem lê o histórico de commits vai conseguir entender a evolução da solução do problema?" Se a reposta for NÃO, a solução será INVÁLIDA[cite: 5].
